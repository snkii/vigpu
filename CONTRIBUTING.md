# Contributing

Bug reports and focused improvement proposals are welcome through GitHub Issues. For larger changes, open an issue first so the scope can be agreed before implementation.

## Pull requests

- Keep changes focused and explain the user-visible effect.
- Use English for source code, comments, and tracked documentation.
- Preserve the low-overhead, read-only dashboard behavior and responsive terminal layout.
- Run `cargo fmt --check` and `cargo check --locked` before submitting.
- Include screenshots or terminal dimensions for visible layout changes when useful.

The maintainer may combine or rewrite project history when integrating changes.
