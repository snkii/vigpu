# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Use [GitHub's private vulnerability reporting](https://github.com/snkii/vigpu/security/advisories/new) or email [iamseonuk@gmail.com](mailto:iamseonuk@gmail.com) with a description, affected versions, and steps to reproduce. The maintainer will acknowledge reports and coordinate a fix and disclosure.

## Supported versions

Security fixes are provided for the latest published release. Users should upgrade to the latest version when a fix is available.
